# InfraViz

**InfraViz** est un outil SaaS qui transforme votre code Terraform en diagrammes d'architecture interactifs.

🔗 **[Accéder à la Documentation Complète](https://SvenAthSDV.github.io/InfraViz/)**

## Fonctionnalités Clés
- **Parsing Instantané** : Glissez-déposez vos fichiers `main.tf`.
- **Visualisation Graphique** : Graphe interactif avec React Flow.
- **Détection des Relations** : Liens automatiques entre les ressources (ex: EC2 -> Subnet).
- **Export PNG** : Sauvegardez vos architectures.

## Installation Locale

```bash
git clone https://github.com/SvenAthSDV/InfraViz.git
cd InfraViz
npm install
npm run dev
```
